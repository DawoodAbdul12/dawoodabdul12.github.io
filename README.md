# Dauda Abdulkadir — Developer Portfolio

A responsive, single-page portfolio website created to present Dauda's web development skills and selected projects.

## Included
- `index.html` — page content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current footer year

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the Google Fonts used in the design; the site otherwise uses local files.

## Publish online
This version is a static website and can be hosted on GitHub Pages, Netlify, or any cPanel hosting account:
1. Upload `index.html`, `style.css`, and `script.js` into the site's document root (often `public_html` on cPanel).
2. Visit your domain and test the page on desktop and mobile.
3. If using a domain root, ensure `index.html` is in the document root.
